# CAURIS AVIATION
Milestone 01: prima esperienza visuale Catania → Lipari, in italiano (/) e inglese (/en).
Next.js App Router, TypeScript, Tailwind CSS, GSAP. Foto e font locali.

## Sviluppo
Node.js >=22 e npm. Ambiente verificato: Node 24.21.0, npm 11.19.0.
In PowerShell, se necessario:
```powershell
$env:Path = 'C:\Program Files\nodejs;' + $env:Path
```
```sh
npm ci
npm run dev
npm run lint
npm run build
npm run start
```
Lo start richiede una build completata. Nessun segreto o servizio esterno necessario.
